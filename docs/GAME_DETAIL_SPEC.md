# MARKETNOVA GAME DETAIL PAGE
## Flagship Intelligence Experience

The Game Detail page is the most important analytical surface in MarketNova.

It should not look like a generic sportsbook game page.

It should not look like a stack of random AI cards.

It should function like a professional sports-market intelligence terminal.

The experience should follow one consistent question:

**What does the sportsbook say, what does MarketNova say, and why are they different?**

The page should progressively move from:

DECISION

→ PRICE

→ MARKET CONTEXT

→ MATCHUP

→ PERSONNEL

→ ENVIRONMENT

→ PROPS

→ RISKS

→ NOVA RESEARCH

→ LIVE / POSTGAME.

---

Then one short paragraph:

### CORE THESIS

Explain the game in 2–4 sophisticated sentences.

Not generic.

Example:

Detroit's current market price appears to be carrying too much weight from Ottawa's recent scoring profile while underpricing Detroit's possession quality, rest advantage and home matchup. The larger discrepancy comes from special-teams normalization and expected even-strength control rather than recent final scores.

Then:

This section should answer:

HOW FAR?

# 13. BEST EXPRESSION

This section should be mandatory.

Title:

# BEST WAY TO EXPRESS THE THESIS

Example:

Primary:
Brewers F5 ML

Secondary:
Brewers ML

Avoid:
Brewers -1.5

Why:

Starter edge is significant, bullpen edge is smaller, and low projected run environment compresses run-line value.

This makes MarketNova much more sophisticated than simple picks.
